# 省份/城市详情宽度优化建议

## 当前问题

详情卡片在 `md:m-4` 容器内占据全宽，Tab 布局下内容（省份名 + 条数）很窄，左右留白过多。

---

## 方案

### 方案 A：限制详情卡片最大宽度（推荐）

给 VCard 加 `max-w-lg`（32rem / 512px），内容紧凑且居中。

```
┌─────────── 表格 ──────────────┐
│                                │
│   ┌── 详情 (max-w-lg) ──┐     │
│   │ [省份详情] [城市详情] │     │
│   │ 搜索...              │     │
│   │ 浙江          5 条   │     │
│   └──────────────────────┘     │
│                                │
│   表格内容...                   │
└────────────────────────────────┘
```

### 方案 B：恢复并排双卡片 + 限制宽度

省份和城市各占一半，每个卡片 `max-h-72`，不需要 Tab 切换，一览无余。

### 方案 C：详情改为可折叠侧栏

详情从下方移到右侧固定侧栏（或抽屉），不占用纵向空间，适合宽屏。

---

## 推荐

**方案 A** 改动最小，一行 class 即可：给 VCard 添加 `max-w-lg`，内容自动紧凑。

请确认后开始修改。
