# 已去过城市高亮显示方案

## 1. 目标

在地图上高亮显示已经去过的城市，使用户能够直观看到自己的城市足迹分布，同时保留当前地图样式、3D 楼房、路网和足迹标记的可读性。

本方案仅用于设计和实现规划，当前阶段不修改 HTML、CSS 或 JavaScript 代码。

## 2. 当前项目基础

项目的足迹数据已经包含城市和行政区编码：

```text
city
cityAdcode
province
provinceAdcode
```

当前地图初始化已经使用高德 JavaScript API 2.0，并开启了 3D 模式、俯仰交互、旋转交互和楼块显示：

```javascript
viewMode: '3D'
pitchEnable: true
rotateEnable: true
showBuildingBlock: true
```

因此，城市高亮应作为独立行政区图层叠加在底图上，而不应修改地图主题或直接覆盖地图瓦片。

## 3. 推荐技术方案

推荐使用：

```text
AMap.DistrictLayer.Country
+ depth: 2
+ cityAdcode 映射
+ fill 回调设置城市颜色
```

高德 `AMap.DistrictLayer.Country` 支持展示中国省级和市级行政区域，并允许通过 `fill` 回调根据行政区属性设置不同填充颜色。城市属性中可以使用 `adcode_cit`、`adcode_pro`、`adcode` 等字段进行匹配。

官方文档：

- [高德 JS API 2.0：简易行政区图](https://lbs.amap.com/api/javascript-api-v2/guide/layers/districtlayer)
- [高德 JS API 2.0：行政区查询](https://lbs.amap.com/api/javascript-api-v2/guide/services/district-search)
- [高德 JS API 2.0：Polygon 多边形](https://lbs.amap.com/api/javascript-api-v2/guide/amap-polygon/polygon)

## 4. 数据映射流程

```text
FOOTPRINT_CONFIG.footprints
        ↓
读取每条足迹的 cityAdcode
        ↓
去重生成 visitedCitySet
        ↓
创建 AMap.DistrictLayer.Country
        ↓
设置 depth: 2
        ↓
在 fill 回调中匹配 properties.adcode_cit
        ↓
已去过城市使用主题色高亮
```

示意逻辑如下，正式实现时再放入 `footprint.js`：

```javascript
const visitedCitySet = new Set(
    footprints
        .map(item => String(item.spec.cityAdcode || ''))
        .filter(Boolean)
);

const visitedCityLayer = new AMap.DistrictLayer.Country({
    zIndex: 8,
    SOC: 'CHN',
    depth: 2,
    styles: {
        fill: properties => {
            return visitedCitySet.has(String(properties.adcode_cit))
                ? 'rgba(240, 120, 165, 0.28)'
                : '';
        }
    }
});
```

实际项目中不建议固定使用 `rgba(240, 120, 165, 0.28)`，应将当前页面的 HSL 主题色转换为 RGBA，使城市高亮跟随 `settings.yaml` 中的 `hsla` 配置。

## 5. 图层层级建议

推荐的视觉层级如下：

```text
地图底图
  ↓
城市高亮行政区图层
  ↓
卫星图层 / 路网 / 路况图层
  ↓
轨迹线和抛物线动画
  ↓
足迹图片标记
  ↓
信息窗口
```

建议城市高亮图层使用：

```javascript
zIndex: 8
```

足迹标记应保持更高层级，避免被城市面覆盖。当前地图开启了 3D 楼块，因此填充透明度不能过高，否则会影响道路、地形和楼房的识别。

## 6. 推荐视觉参数

### 已去过城市

```text
填充颜色：当前主题色
填充透明度：0.22 ～ 0.32
城市边界：主题色，透明度 0.35 左右
```

### 未去过城市

```text
填充：透明
城市边界：浅灰色，透明度 0.16 ～ 0.22
```

### 省级边界

```text
颜色：白色或浅灰色
透明度：0.30 ～ 0.40
线宽：1 ～ 1.5
```

推荐默认视觉效果：

```text
已去过城市 = 浅粉色低透明度填充 + 淡主题色边界
未去过城市 = 不填充 + 弱边界
```

这样既能突出足迹范围，也不会让地图变成大面积色块。

## 7. 与现有功能的兼容性

### 地图样式

城市高亮图层独立于 `mapStyle`，因此不会破坏标准、卫星、灰色或其他高德地图主题。

### 3D 楼房和俯仰

行政区图层属于平面覆盖层，建议使用较低透明度。地图俯仰时仍可看到楼房立体块，不应使用不透明填充遮挡建筑细节。

### 足迹标记

足迹图片标记继续保留在上层，城市色块只作为区域背景提示，不替代原有标记。

### 路网和路况

路网、路况图层仍然可以单独开关。城市高亮不应绑定到路网或路况开关。

### 主题色

高亮颜色应复用页面主题 HSL，保证统计面板、工具栏、时间线、标记点和城市区域保持统一视觉语言。

## 8. 交互建议

第一版建议只做静态高亮，不增加复杂交互。

后续可以增加：

1. 鼠标悬停城市时显示城市名称。
2. 点击城市时显示该城市的足迹数量。
3. 点击城市后筛选时间线中的相关足迹。
4. 城市高亮边界在悬停时短暂增强。
5. 在统计面板中增加“已去过城市数量”。

如果增加城市交互，应避免只依赖颜色传达信息，同时提供城市名称或足迹数量文字提示。

## 9. 配置项建议

第一版可以直接默认开启，不增加设置项。

如果需要用户控制，建议在 `settings.yaml` 增加：

```yaml
- $formkit: checkbox
  label: 高亮已去过的城市
  name: highlightVisitedCities
  value: true
  help: 使用主题色显示已经去过的城市区域
```

后续还可以增加高亮方式：

```text
城市填充
城市边框
填充 + 边框
```

默认推荐：

```text
填充 + 边框
```

## 10. 备用方案：DistrictSearch + Polygon

备用方案是逐个城市查询边界，再使用 `AMap.Polygon` 绘制：

```text
cityAdcode
    ↓
DistrictSearch 查询城市边界
    ↓
获取 boundaries
    ↓
AMap.Polygon 绘制区域
```

高德官方支持通过 `DistrictSearch` 获取行政区边界，再使用 `AMap.Polygon` 绘制多边形。

该方案不作为首选，原因如下：

- 每个城市可能产生一次查询。
- 足迹城市较多时，初始化速度会下降。
- 需要额外处理请求失败和边界缓存。
- 多城市多边形覆盖物会增加渲染压力。
- 需要额外管理图层销毁和重复绘制。

只有在 `DistrictLayer.Country` 无法满足特殊边界样式或复杂交互需求时，才建议采用该方案。

## 11. 正式实施时的文件范围

### 必须修改

```text
src/main/resources/static/js/footprint.js
```

主要内容：

- 读取 `cityAdcode` 并去重。
- 加载或初始化行政区图层。
- 根据城市编码设置填充样式。
- 在地图销毁或重新初始化时清理图层。

### 可选修改

```text
src/main/resources/extensions/settings.yaml
```

主要内容：

- 增加是否开启城市高亮的配置。
- 增加高亮模式配置。

### 通常不需要修改

```text
src/main/resources/templates/footprint.html
src/main/resources/static/css/footprint.css
```

行政区填充由高德图层渲染，不是普通 HTML 元素，因此通常不需要 CSS。

## 12. 性能与异常处理

实现时需要注意：

- `cityAdcode` 为空时跳过该足迹。
- 使用 `String()` 统一编码类型，避免数字和字符串比较失败。
- 使用 `Set` 去重，避免重复城市重复处理。
- 足迹为空时仍允许地图正常加载。
- 行政区图层加载失败时不能阻塞地图和时间线。
- 不要因为城市高亮调用 `map.setFitView()`，避免改变当前地图视野。
- 处理 `prefers-reduced-motion` 时不添加额外动画。

## 13. 最终推荐结论

最终采用：

```text
AMap.DistrictLayer.Country
+ SOC: 'CHN'
+ depth: 2
+ cityAdcode Set 匹配
+ 主题色低透明度填充
+ 主题色弱边界
+ zIndex: 8
```

该方案不需要为每个城市单独请求边界数据，性能和实现复杂度更适合当前项目，也能兼容现有的 3D 地图、地图主题、路网、路况、轨迹线和足迹标记。
