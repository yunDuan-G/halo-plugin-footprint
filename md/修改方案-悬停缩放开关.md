# 悬停缩放开关功能 - 修改方案

## 需求描述

在 settings.yaml 的基本设置中增加一个"是否启用悬停缩放"的开关选项。开启时保持现有行为（悬停时间线卡片 → 缩放定位 → 渲染抛物线），关闭后悬停卡片直接渲染抛物线，不进行地图缩放定位。

---

## 涉及修改的文件（共5个）

| # | 文件 | 修改内容 |
|---|------|---------|
| 1 | src/main/resources/extensions/settings.yaml | 新增 enableHoverZoom 表单项 |
| 2 | src/main/java/cc/lik/footprint/dto/BaseConfig.java | 新增 enableHoverZoom 字段 |
| 3 | src/main/java/cc/lik/footprint/service/impl/FootprintServiceImpl.java | 读取 enableHoverZoom 配置值 |
| 4 | src/main/resources/templates/footprint.html | 将 enableHoverZoom 注入 FOOTPRINT_CONFIG |
| 5 | src/main/resources/static/js/footprint.js | 在 handleEnter 中判断开关，跳过缩放逻辑 |

---

## 详细修改

### 1. settings.yaml - 新增表单控件

在 group: base（基本设置）的 ormSchema 中，于 hsla 配置项之后增加一个 checkbox 开关项：

`yaml
- $formkit: checkbox
  label: 启用悬停缩放
  name: enableHoverZoom
  value: true
  help: "悬停时间线卡片时，是否先缩放到对应位置再显示抛物线动画"
`

**插入位置**: 在 hsla 的 $formkit: text 下方，gaoDeKey 上方。

---

### 2. BaseConfig.java - 新增字段

`java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class BaseConfig {
    private String title;
    private String gaoDeKey;
    private String gaoDeWebKey;
    private String describe;
    private String hsla;
    private String logoName;
    private String mapStyle;
    private String markerStyle;
    private Boolean enableHoverZoom;  // ← 新增: 是否启用悬停缩放，默认 true
}
`

---

### 3. FootprintServiceImpl.java - 读取配置值

在 getConfigByGroupName() 方法的 BaseConfig 构造中新增：

`java
item.path("enableHoverZoom").asBoolean(true)  // ← 新增，默认 true
`

---

### 4. footprint.html - 注入前端配置

在 window.FOOTPRINT_CONFIG 对象中新增：

`javascript
enableHoverZoom: /*[[]]*/ true  // ← 新增
`

---

### 5. footprint.js - 核心逻辑修改

在 handleEnter 函数的两个分支中，增加优先判断 enableHoverZoom。

**修改点一（关联标记点分支 ~L731-L740）:**

`javascript
// 当前:
if (!byOverlays[0].toString().startsWith(currentZoom)) {
    zoomOn(map, card, newPosition, byOverlays[0], 1);
    await moveToLocation(map, newPosition, byOverlays[0], 0);
} else {
    loadParabolaAnimation(card, map);
    zoomOff(map);
}

// 改为:
if (!window.FOOTPRINT_CONFIG.enableHoverZoom) {
    zoomOff(map);
    loadParabolaAnimation(card, map);
} else if (!byOverlays[0].toString().startsWith(currentZoom)) {
    zoomOn(map, card, newPosition, byOverlays[0], 1);
    await moveToLocation(map, newPosition, byOverlays[0], 0);
} else {
    loadParabolaAnimation(card, map);
    zoomOff(map);
}
`

**修改点二（单个标记点分支 ~L742-L763）:**

`javascript
// 当前:
if (needsMovement) {
    zoomOn(map, card, position2, zoom, 1);
    frequency = 1;
    const newOverlays2 = ...;
    // ... overlays 处理保持不变 ...
    await moveToLocation(map, newPosition2, mergedOverlay[0], 5);
} else {
    loadParabolaAnimation(card, map);
    zoomOff(map);

} else {
    loadParabolaAnimation(card, map);
    zoomOff(map);
}
`

## 行为对比

| enableHoverZoom | 悬停卡片行为 |
|---|---|
| 	rue（默认） | 缩放定位 → 渲染抛物线（保持现有行为） |
| alse | 直接渲染抛物线，地图无变化 |

---

## 测试要点

1. Halo后台 → 足迹插件设置 → 基本设置中确认"启用悬停缩放"复选框出现，默认勾选
2. 勾选状态下悬停卡片行为与现有一致
3. 取消勾选后悬停卡片直接显示抛物线，不缩放不移地图
4. 再次勾选后恢复缩放定位行为
